# Django E-commerce Website

A full-stack e-commerce web application developed using Python and Django, with a frontend built using HTML and CSS.

## Features

- Product listing and product details
- Add new products
- Update existing products
- Delete products
- Customer details management
- User login functionality
- Order management
- Product images and styling
- Database integration

## Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Development Environment:** Visual Studio Code

## Project Structure

- `ProductApplication/` – Django application
- `static/` – CSS files and product images
- `templates/ProductApplication/` – HTML templates
- `web_project/` – Django project configuration

## Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project:
   ```bash
   cd AdiDjango2
   ```

3. Create a virtual environment:
   ```bash
   python -m venv .venv
   ```

4. Activate the environment:
   ```bash
   .venv\Scripts\activate
   ```

5. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

6. Apply migrations:
   ```bash
   python manage.py migrate
   ```

7. Start the development server:
   ```bash
   python manage.py runserver
   ```

8. Open:
   ```text
   http://127.0.0.1:8000/
   ```
